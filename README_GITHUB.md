# LID Option Menu Mod

A small mod for **LET IT DIE** that adds extra options to the pause menu and a Free Camera hotkey.

## Features

- **Storage** — opens the Coin Locker.
- **Shop** — opens the Part Shop.
- **F5** — toggles Free Camera.

## Menu Order

```text
Death Bag
Storage
Shop
Rolodex
Insurance
Options
Return to Title
Exit Game
```

## Build

The project is intended to be compiled as:

```text
Release | x64
```

## Notes

The added menu entries use the game's native UI and functions.

## Installation

Place the compiled DLL in your mod loader's mods folder and start the game.
